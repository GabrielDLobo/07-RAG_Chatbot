# Project Overview

This document provides a high-level overview of the RAG Chatbot project.

## Introduction

The RAG Chatbot is a Streamlit-based application that allows users to upload PDF documents and ask questions based on the document content.

## Purpose

The main objective is to combine retrieval and generation so answers are grounded in indexed document chunks.

## Key Features

- PDF upload and processing
- Chunking and embedding generation
- ChromaDB local vector storage
- Conversational interface in Streamlit
- LLM responses via Groq

## Technology Highlights

- Python + Streamlit
- LangChain orchestration
- Hugging Face embeddings
- ChromaDB persistence
- Groq API integration
